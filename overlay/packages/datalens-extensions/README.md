# datalens-extensions (Ring 2)

**Для ревьюеров datalens-tech:** universal-улучшения в стиле official, готовые к PR.

| | |
|--|--|
| Реестр | `src/features/registry.ts` |
| RFC | `overlay/platform/upstream-rfc/` |
| Процесс PR | `docs/dev/CONTRIBUTING_UPSTREAM.md` |
| Статус port UI | `docs/dev/ui-overlay-official-audit.md` |

Код **переносится** из `overlay/components/datalens-ui` → `overlay/patches/datalens-ui/<module>/` (фаза 1 мастер-плана).  
**Не сюда:** Flight Groups → `packages/org-private` (PRIVATE).

См. `docs/dev/upstream-ready-repository.md`, `docs/dev/ydlos-master-plan.md`.
