# Документация YDLOS

**Для кого:** бизнес-пользователи, аналитики, администраторы, разработчики DataLens OSS.

Платформа = [DataLens Open Source](https://github.com/datalens-tech/datalens) (vendor) + overlay YDLOS. Обновление ядра — без форка monorepo.

> Это **публичное** оглавление. Внутренние runbook и корпоративные материалы — только в корпоративном репозитории организации.
