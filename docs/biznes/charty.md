# Чарты

**Для кого:** аналитики.

## Типы

- **На датасете (Wizard)** — визуальный конструктор.
- **QL** — SQL-запрос в диалекте БД (только SELECT).

## Визуализации

Линейные, столбчатые, круговые, таблицы, сводные, карты, indicator и др.

На prod может быть `HC=0` (D3) — не все типы из облака. См. [../ops/vizualizacii-hc0.md](../ops/vizualizacii-hc0.md).

## Диагностика

**Inspector** в редакторе чарта — просмотр запроса и ошибок.

Справочник типов: https://datalens.ru/opensource/docs/ru/visualization-ref/
