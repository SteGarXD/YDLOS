# Датасеты

**Для кого:** аналитики.

Датасет — модель полей поверх таблиц подключения: типы, агрегации, связи (join), вычисляемые поля, предфильтр.

## Рекомендации

- Тяжёлые join — по возможности в БД (материализованная витрина).
- Неиспользуемые поля — отключать.
- Параметры датасета — для гибкой фильтрации в чартах.

Оптимизация: [../ops/optimizaciya.md](../ops/optimizaciya.md).
