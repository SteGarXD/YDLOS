# Дашборды

**Для кого:** аналитики.

## Виджеты

Чарт, селектор, текст, заголовок.

## Связи и фильтры

- **Связи** — согласование полей между виджетами (aliases).
- **Селекторы** — фильтр на вкладке.
- **Параметры дашборда** — значения при открытии; в URL: `?param=value`.
- **state** в URL — поделиться текущими настройками фильтров (скопировать адресную строку).

Спец. форматы дат: `__relative_-7d`, интервалы `__interval_...`.

## Версии

История изменений конфигурации дашборда — 3 месяца. Правки в Wizard/QL в версию дашборда не входят.

Официально: https://datalens.ru/opensource/docs/ru/concepts/dashboard.html
