# Оптимизация

**Для кого:** аналитики и администраторы.

Официальные рекомендации: https://datalens.ru/opensource/docs/ru/concepts/optimization_recommendations.html

## Кратко

- Витрины в БД, не тяжёлые join в UI.
- Справочники для селекторов — отдельные лёгкие датасеты.
- Меньше виджетов на вкладке дашборда.
- Предфильтр на датасете.
