# Визуализации при HC=0

**Для кого:** аналитики.

На prod YDLOS может быть отключён Highcharts (`HC=0`) — используется D3. Не все типы графиков из облака доступны.

Включение HC=1: лицензия Highcharts — см. official docs.

Проверка: создать тестовый чарт нужного типа; при отсутствии — альтернативный тип или HC=1 по согласованию с ИБ.
