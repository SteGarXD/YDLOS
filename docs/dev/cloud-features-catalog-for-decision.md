# Каталог возможностей DataLens Cloud — для решения «что нам нужно»

**Для кого этот документ:** вы (владелец платформы) отмечаете NEED / LATER / NO.  
**Аудитории внутри компании:**

| Код | Кто |
|-----|-----|
| **VIEW** | Смотрит дашборды, фильтрует, иногда share-ссылка |
| **ANALYST** | Подключения, датасеты, чарты, дашборды, экспорт |
| **ADMIN** | Пользователи, роли, настройки сервиса, публикация |
| **DEVOPS** | Установка, SSO, бэкапы, мониторинг, обновления |
| **DEV** | API, кастомные чарты, встраивание в порталы |
